# Chess Cube

An 8×8×8 Rubik’s cube whose faces are chessboards in starting position.

- Orbit the 3D cube
- The 2D gizmo shows the face you’re looking at
- Arrows or a swipe turn a row or column 90°
- Complementary colour pairs per face, pieces face the centre of each board

Live: [chess-cube.grok.me](https://chess-cube.grok.me)

```bash
npm install
npm run dev
```

Opens on port 8080.
